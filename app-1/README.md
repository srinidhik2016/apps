# Language Tutor SPA for Kids

A colorful single-page language tutor app for kids with support for:

- English
- French
- Spanish

## What is included

- Language switcher
- Image flashcards with reveal/hide meaning
- Quick multiple-choice quiz
- Simple typing practice with instant feedback

## Run locally

1. Open `index.html` in your browser.
2. Choose your language.
3. Start learning with picture cards, quiz, and practice.

No build tools are required for this starter version.
