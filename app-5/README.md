# App 5 - Recall

A calm, professional chat app that remembers what you tell it about your work day, and answers when you ask about it later.

## How it works

- Tell Recall something, and it saves it as a memory tied to today's date (e.g. "Today I fixed the printer at the office.").
- Ask about a day later, and Recall looks it up: "What did I do yesterday?", "What happened last Monday?", "What did I do on August 10?", "What did I do this week?".
- If you ask about a topic instead of a day (e.g. "Did I talk to the printer guy?"), Recall searches saved memories for matching words.
- Memories are stored in the browser's local storage on that device, so they persist between visits even though the chat itself resets.
- Includes a web app manifest so it can be installed to a home screen.

Open [index.html](index.html) to use the app.
